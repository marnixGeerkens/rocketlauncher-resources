# Contributing

To report a problem or suggest an improvement, email support@rocketlauncher.ai, the contact published on RocketLauncher's privacy page. Include the resource ID, version, platform/version, expected behavior and reproduction steps. Remove tokens, account identifiers, personal information and private project files. No message is sent by downloading or validating this package.

Use this repository's Issues for reproducible problems and Pull Requests for improvements. Do not submit private website or Brain files. Changes to imported components must retain their upstream source, commit and license notices; upstream contributions are welcome.

Contributions must solve a concrete task and identify the platforms they support. Include useful installation/use instructions, an example, limitations, sources, author, license, version history and truthful verification evidence. Keep the ID and existing slug stable. Update each affected translation completely or withhold the incomplete variant from publication. Existing English and Dutch versions must remain complete.

Only submit work you own or may redistribute. For an external project without confirmed redistribution permission, add an attributed source link and original explanation, not a copied file. Original hosted downloads currently use MIT. Retain author and license notices. Do not execute contributed scripts or commands during review with production credentials.

Run the package validator, inspect the actual file diff, and test the described behavior in an isolated project. Record what passed and what remains untested. A reviewer checks factual changes, compatibility, translations and licensing before release. Installation, authentication, payment, affiliate and security changes require explicit owner review.
