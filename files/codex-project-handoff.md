# Project handoff checklist

Before work, read AGENTS.md and the current handoff. Inspect git status and the active branch. Preserve uncommitted work.

Record the objective, current behavior, affected routes and files, relevant commands, and release boundary.

Implement the smallest complete change using existing project patterns. Inspect callers before changing a shared interface.

Run the appropriate local checks. Distinguish source review, unit tests, browser evidence, provider evidence and production behavior.

At handoff, record changed files, commands and results, known failures, next steps and rollback. Never record credentials, tokens or personal customer data.

Do not claim completion while required checks remain unresolved. Do not publish or push to production without explicit authorization.
