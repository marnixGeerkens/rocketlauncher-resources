# Website review

Read the repository instructions and inspect the diff before changing files.
Identify the changed routes and their callers. Preserve unrelated work.
Start the existing local preview using the repository's documented command.
Check a changed detail page as well as the homepage at desktop and narrow mobile widths.
Use the keyboard to reach every changed control. Check visible focus, Escape and focus restoration for dialogs.
Follow one successful flow and one failure or empty-result flow. Refresh a deep link.
Check the initial HTML for the page title, canonical, main content and structured data.
Run the project's relevant tests. Report exact commands, observed results and unverified external behavior.
Do not deploy, submit forms to real customers, spend money or change production without explicit authorization.
